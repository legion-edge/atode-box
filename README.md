# あとでボックス

> 今じゃない。でも忘れたくない。

あとで確認したいURL、行きたい場所、買いたいもの、アイデアやメモを、整理せずにすばやく保存するモバイルアプリです。保存内容の性質と生活時間から、処理しやすいタイミングで思い出せることを目指します。

## 現在地

Phase 1のホーム入力、ローカル保存、7カテゴリの基本分類、生活時間設定、ローカル通知、通知一覧、詳細画面を実装しています。自由入力の「登録」と、ボタン操作の「貼り付けて追加」で保存できます。明確なURLホストや日本語の手掛かりから端末内で分類し、曖昧な入力は「メモ」にします。保存時には分類や通知時刻を尋ねません。初回に生活時間の既定値を案内し、後から設定画面で変更できます。通知では「開く」「完了」「あとで」を選べます。一覧では次回通知日時、カテゴリ、今日・明日以降・休日・1週間後以降・完了済みを確認できます。詳細画面には原文、任意のタイトルとURL、保存日時、次回通知日時、通知コンテキストを表示します。URLを外部アプリで開いても完了にはしません。タイトル・URL・カテゴリを編集でき、確認後の削除で次回通知を取り消します。原文は編集・削除後も保存記録に保持します。

## 開発

Flutter stableと対象プラットフォームのツールチェーンを用意し、リポジトリのルートで実行します。

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

iOSビルドにはmacOSとXcodeが必要です。Windows上でのDart解析・テストは、iOS実機／シミュレータ検証の代わりにはなりません。
